# 悬浮备忘录

[English](./README.md) · **简体中文**

DeepSeek Harness 网页端的悬浮备忘录。点击右下角的圆形按钮，即可打开
类似 Notion 的编辑面板，每个页面对应一个标签。

## 安装

```sh
git clone https://github.com/yuzu-dsh-plugins/floating-notes.git
```

在 DSH 插件管理器中，将克隆下来的目录安装为本地 bundle。如果当前会话提供
`plugin_manager` 工具，可通过 `install_bundle` 指定该目录的绝对路径。
注册的 bundle 名称为 `dsh-floating-notes`。仓库已包含构建好的 `client.js`，
可以直接安装。

## 功能简介

![插件图标](./icon.svg)

面板内置基于 ProseMirror 的 TipTap 编辑器，支持撤销、跨段选取、输入法组合输入和
富文本粘贴。可以新建、切换、重命名和删除页面。每页独立保存正文、创建时间和最近编辑时间。

## 悬浮按钮与面板

- 可拖动按钮。位置保存在当前浏览器，在加载页面或调整窗口大小时会限制在可视区域内。
- 位置按距最近横向和纵向屏幕边缘的距离保存。调整窗口大小时，按钮尽量留在原来的
  象限并保持相对边距。旧版保存的绝对坐标会在加载时转换。
- 点击按钮可打开或关闭面板，结束拖动时不会误触发。面板在按钮上下、左右空间更大的一侧展开，
  与按钮保持 12 像素的垂直间距，左缘或右缘对齐。
- 保存的面板尺寸是显示上限。空间不足时面板会缩小，空间恢复后会恢复到保存的尺寸。
- 可拖动远离按钮的两个边缘，或拖动它们交汇的角同时调整宽高。例如按钮在右下角时，
  可拖动面板左上角缩放。鼠标移到手柄上时会显示缩放光标。缩放时会尽量满足
  320×240 像素的最小尺寸并适配窗口。重新打开面板或移动按钮后，面板会重新定位。
- 点击标签栏的锁形按钮后，点击面板外部不会关闭面板。仍可用 `Esc`、面板关闭按钮
  或悬浮按钮关闭。关闭后锁定状态会重置。

## 编辑

| 在行首输入 | 结果 |
|---|---|
| `# `、`## `、`### ` | 一级、二级、三级标题 |
| `- ` 或 `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `[] ` 或 `[ ] ` | 带复选框的待办事项 |
| `> ` | 引用 |
| `---` | 分隔线 |
| `/` | 可输入关键词筛选的块菜单 |

行内 Markdown 也可使用，例如 `**粗体**`、`*斜体*`、`~~删除线~~` 和 `` `代码` ``。

- `Enter` 拆分段落或继续列表。段落开头的 `Backspace` 可与上一段合并，
  `Tab` 和 `Shift-Tab` 可调整列表项缩进。
- 在空的待办项、无序列表项或有序列表项中，按 `Enter`、`Backspace` 或 `Delete`
  可退出列表。空项在列表中间时，前后的内容会保留为两个列表。只包含空格或换行的项也算空项。
- 编辑器打开时，用 `Cmd/Ctrl-Z` 撤销，用 `Shift-Cmd/Ctrl-Z` 重做。
  切换页面或关闭面板会重置撤销历史。
- 在 `/` 菜单中用方向键选择、`Enter` 应用、`Esc` 关闭。
  菜单未打开时，`Esc` 会关闭面板。
- 悬浮按钮上的数字是所有页面的未完成待办数，面板底部显示当前页的未完成待办数。

## 页面

- 页面标签按创建时间排序。标签栏可以横向滚动，并保持当前页标签可见。
- 点击 `+` 新建空白页，光标会自动移到标题栏。直接编辑标题即可重命名。
- 点击标签上的 `×` 后，可在该标签内确认删除或取消。删除最后一页时会创建一个新的空白页。
- 没有标题时，标签使用正文第一行，正文为空时显示「未命名」。将鼠标移到标签上可查看最近编辑时间。

## 存储

按钮位置单独保存在 `dsh-floating-notes/position`，结构为
`{ xSide, x, ySide, y }`。面板尺寸单独保存在 `dsh-floating-notes/size`，
结构为 `{ width, height }`。移动按钮或调整大小时，无须重写页面内容。

页面集合保存在浏览器 `localStorage` 的 `dsh-floating-notes/v1` 中，结构为
`{ version: 5, activeId, pages: [{ id, title, doc, createdAt, updatedAt }], deleted: { [id]: timestamp } }`。
`doc` 是 ProseMirror JSON。每次修改后等待 400 毫秒再保存。写入失败时，页脚会显示
「未保存到本机」，鼠标悬停可查看原因。首次使用时会提示数据仅保存在本机。

- 每次保存时按页面 ID 与已有数据合并，保留 `updatedAt` 更新的一份。
  如果其他浏览器标签页在 400 毫秒等待期间保存，当前标签页待保存的输入可能被覆盖。
- 页面删除记录保留七天，用来过滤较旧的已删除页面副本。
- 浏览器标签页隐藏或关闭时，编辑器会尝试写入待保存内容。卸载插件可能取消待保存操作。
- 整个页面集合无法读取时，插件会尝试将原始数据复制到
  `dsh-floating-notes/v1.corrupt-<time>`，并显示恢复提示。

旧版 TipTap 的单页格式 `{ title, doc }` 和更早的块数组格式 `{ title, blocks }`
都会转换成集合中的第一页。备忘录保存在当前浏览器中，同源的 DSH 会话共享同一份内容。

## 架构

| 部分 | 实现 |
|---|---|
| 插槽 | `shell.overlay`，覆盖整个界面，默认允许鼠标事件穿透 |
| 入口 | `dsh-floating-notes`，排序值为 40 |
| 界面 | 复用宿主页面的 React |
| 编辑器 | TipTap 2、StarterKit、Placeholder、TaskList 和 TaskItem |
| 构建 | esbuild 打包为 IIFE，通过加载器使用宿主 React |
| 宿主端 | 空的 `apply()`，用于激活插件 |
| 主题 | 使用宿主的 `--dsw-alias-*` 主题变量 |
| 多语言 | `dsh-floating-notes` 命名空间，包含简体中文和英文词典 |

`src/entry.js` 通过 `window.__ModuleLoader__.load` 注册模块。工厂函数用宿主的
`require` 获取 React，再经由 `src/runtime.js` 提供给插件。

## 开发

```sh
npm ci           # 安装 TipTap、esbuild 和冒烟测试所需的 jsdom
npm run build    # src/ -> client.js
npm run check    # 运行页面流程、数据迁移、编辑与撤销测试
```

构建产物 `client.js` 随源码提交。重新构建后，刷新 Harness 页面以加载新文件。

## 文件

| 文件 | 用途 |
|---|---|
| `index.js` | 宿主入口，提供空的 `apply` 以激活插件 |
| `client.js` | 浏览器端构建产物，由构建命令生成 |
| `src/` | 编辑器、页面视图、存储、词典和样式 |
| `checks/render.mjs` | 页面流程、迁移、编辑和撤销的无界面测试 |
| `cordis.patch.yml` | 向加载器添加 `floating-notes` |
| `locale/en.json`、`locale/zh.json` | 插件管理器显示的标题和说明 |
| `icon.svg` | 插件列表图标 |

## 已知限制

- 选中文本时暂无格式工具栏。可以用 Markdown 快捷输入或 `Cmd-B`、`Cmd-I` 设置粗体和斜体。
- 编辑器目前不支持链接、图片、表格和代码块。
- 目前无法跨页面搜索。
- 编辑器最多加载 200 页。超过上限后新建的页面可能在重新加载时从面板中消失。
- 存储按浏览器来源隔离，同一来源下的所有工作区和会话共享备忘录。
